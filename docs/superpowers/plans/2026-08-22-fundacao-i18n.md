# Fundação de i18n (pt/de) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O site de cliente da Animora passa a servir português (sem prefixo, como hoje) e alemão (`/de/...`), com toda a casca de interface bilingue via `next-intl`. O admin (Payload) não é tocado.

**Architecture:** `next-intl` com `localePrefix: 'as-needed'` (`pt` é `defaultLocale`, sem prefixo; `de` ganha `/de`). Toda a árvore de rotas de cliente move para `app/[locale]/`. Mensagens em `apps/web/messages/{pt,de}.json`, um namespace por componente/página. Um teste garante que as duas árvores de chaves são idênticas.

**Tech Stack:** Next.js 15 (App Router), React 19, `next-intl` 4.x, vitest, pnpm workspace.

**Spec:** `docs/superpowers/specs/2026-08-22-fundacao-i18n-design.md`

## Global Constraints

- `pt` fica sem prefixo de URL (`/produtos`); só `de` ganha `/de/...` — preserva as URLs atuais.
- Sem redirecionamento automático por `Accept-Language` na raiz — só troca de idioma explícita (seletor + cookie `NEXT_LOCALE`, que o middleware do next-intl já lê nativamente).
- Nomes de segmento de rota NÃO são traduzidos nesta fase (`/de/produto/[slug]`, não `/de/produkt/[slug]`).
- `apps/api/**` não é tocado — o admin já está em `i18n: { supportedLanguages: { pt } }`.
- Conteúdo do catálogo (título/descrição de produto, vindo do Payload) continua só em português nos dois idiomas nesta fase — é o sub-projeto 2, fora deste plano.
- Registo (voz de marca): alemão usa a forma informal "du" em toda a copy, espelhando o registo próximo do "tu" em português — nunca "Sie".
- Todo o texto novo entra em `messages/pt.json` e `messages/de.json` com as MESMAS chaves — o teste de paridade em `src/i18n/messages.test.ts` (Task 1) falha se divergirem.

Todas as chaves de `messages/pt.json`/`messages/de.json` (ver conteúdo completo abaixo) — as tarefas seguintes consomem-nas por `useTranslations('Namespace')`/`getTranslations({locale, namespace: 'Namespace'})`, nunca criam chave nova sem a espelhar nos dois ficheiros.

- [ ] **Step 2: Criar `apps/web/src/i18n/routing.ts`**

```ts
import { defineRouting } from 'next-intl/routing'

export const routing = defineRouting({
  locales: ['pt', 'de'],
  defaultLocale: 'pt',
  localePrefix: 'as-needed',
  // `false` porque o next-intl, por omissão, deteta o idioma preferido do
  // browser (`Accept-Language`) em pedidos sem prefixo e redireciona `/` para
  // `/de` quando esse for o preferido — exatamente o redirecionamento
  // automático que a spec exclui («sem redireccionamento automático por
  // Accept-Language na raiz»). Com isto desligado, `/` serve sempre pt; só um
  // link/URL explícito com `/de` (ou o seletor de idioma) muda de idioma.
  localeDetection: false,
})
```

- [ ] **Step 3: Criar `apps/web/src/i18n/navigation.ts`**

```ts
import { createNavigation } from 'next-intl/navigation'
import { routing } from './routing'

export const { Link, redirect, usePathname, useRouter, getPathname } = createNavigation(routing)
```

- [ ] **Step 4: Criar `apps/web/src/i18n/request.ts`**

```ts
import { hasLocale } from 'next-intl'
import { getRequestConfig } from 'next-intl/server'
import { routing } from './routing'

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale
  const locale = hasLocale(routing.locales, requested) ? requested : routing.defaultLocale

  return {
    locale,
    messages: (await import(`../../messages/${locale}.json`)).default,
  }
})
```

```tsx
import type { Metadata } from 'next'
import { notFound } from 'next/navigation'
import { hasLocale, NextIntlClientProvider } from 'next-intl'
import { getMessages, getTranslations, setRequestLocale } from 'next-intl/server'
import { Bricolage_Grotesque, Figtree } from 'next/font/google'
import '../../styles/globals.css'
import { routing } from '../../i18n/routing'
import { Header } from '../../components/layout/Header'
import { Footer } from '../../components/layout/Footer'
import { CarrinhoProvider } from '../../modules/cart/CarrinhoProvider'

/**
 * As duas famílias da loja, auto-alojadas por `next/font` — sem pedido a
 * servidores de fontes em tempo de execução e sem salto de tipo ao carregar.
 *
 * Fraunces + Nunito Sans (a combinação anterior) é a escolha-reflexo de
 * qualquer gerador de design — foi apontada como "cara de IA" na crítica que
 * levou a este redesign. Bricolage Grotesque nos títulos tem carácter próprio
 * sem cair em serifa editorial; Figtree no texto continua legível. Duas e
 * mais nenhuma.
 */
const fonteTitulo = Bricolage_Grotesque({
  subsets: ['latin'],
  variable: '--fonte-titulo',
  display: 'swap',
})

const fonteTexto = Figtree({
  subsets: ['latin'],
  variable: '--fonte-texto',
  display: 'swap',
})

const HTML_LANG: Record<string, string> = { pt: 'pt-PT', de: 'de-DE' }

type Props = { children: React.ReactNode; params: Promise<{ locale: string }> }

export function generateStaticParams() {
  return routing.locales.map((locale) => ({ locale }))
}

export async function generateMetadata({ params }: Props): Promise<Metadata> {
  const { locale } = await params
  const t = await getTranslations({ locale, namespace: 'Home' })

  return {
    title: { default: t('metaTitulo'), template: '%s · Animora' },
    description: t('metaDescricao'),
  }
}

export default async function LocaleLayout({ children, params }: Props) {
  const { locale } = await params
  if (!hasLocale(routing.locales, locale)) notFound()

  setRequestLocale(locale)
  const [t, messages] = await Promise.all([
    getTranslations({ locale, namespace: 'Layout' }),
    getMessages(),
  ])

  return (
    <html lang={HTML_LANG[locale] ?? locale} className={`${fonteTitulo.variable} ${fonteTexto.variable}`}>
      <body>
        <a
          href="#conteudo"
          className="sr-only focus:not-sr-only focus:absolute focus:left-4 focus:top-4 focus:z-50 focus:rounded-lg focus:bg-ink focus:px-4 focus:py-2 focus:text-cream"
        >
          {t('saltarParaConteudo')}
        </a>
        {/*
          O carrinho envolve a aplicação inteira porque o cabeçalho mostra o
          número de artigos em todas as páginas. Não lê cookies nem sessão do
          lado do servidor de propósito: `cookies()` aqui tornava TODAS as
          páginas dinâmicas, incluindo as fichas de produto, que são geradas
          estaticamente. A sessão é perguntada do cliente, depois de montar.

          `messages` tem de ser passado explicitamente ao provider — sem ele,
          `useTranslations` (a versão para Client Components, usada em
          `SeletorIdioma`, `FiltrosCatalogo`, `Totais`, `FormularioCheckout`,
          etc.) não tem de onde ler as traduções no browser.
        */}
        <NextIntlClientProvider messages={messages}>
          <CarrinhoProvider>
            <Header />
            {children}
            <Footer />
          </CarrinhoProvider>
        </NextIntlClientProvider>
      </body>
    </html>
  )
}
```

```tsx
  titulo,
  descricao,
  caminho,
  categoriaId,
  filtros,
  atributosAtivos,
  vazio,
}: Props) {

  const q = filtros.q ?? ''

      filtros.precoMin !== undefined ||
      Object.keys(filtros.atributos ?? {}).length > 0,

          bounds={bounds}
          atributos={facetas}
          filtrosAtuais={filtros}
```

```tsx
'use client'

import Image from 'next/image'
import { useEffect, useState } from 'react'
import { useTranslations } from 'next-intl'
import { formatEuros } from '@animora/core'

import { guardarMorada } from '../../../modules/account/acoes'
import type { Morada } from '../../../modules/account/sessao'
import { carregarLinhas, comprar, type FaltaStock } from '../../../modules/cart/acoes'
import { useCarrinho } from '../../../modules/cart/CarrinhoProvider'
import { totaisDoCarrinho, type LinhaCarrinho } from '../../../modules/cart/carrinho'
import { Link, useRouter } from '../../../i18n/navigation'
import { Totais } from '../../../components/ui/Totais'

/**
 * O checkout.
 *
 * Sem pagamento — a encomenda nasce a aguardar. O que este ecrã faz é: mostrar
 * os preços **relidos agora** do servidor, recolher a morada, e enviar ao
 * `POST /api/checkout` uma lista de `{ variantId, qty }`. Nenhum total, nenhum
 * preço. O servidor refaz a conta com os preços da base e é esse o número que
 * fica na fatura; o total aqui em cima sai da mesma função (`calcularTotais`)
 * alimentada pelos mesmos preços, e é por isso que é o mesmo número.
 *
 * A recusa por falta de stock (409) mostra o que falta e **não mexe no
 * carrinho**: quem estava a comprar cinco coisas não perde as outras quatro
 * porque outra pessoa levou a última unidade de uma.
 *
 * O formato de morada (código postal, `pattern`) continua só português nesta
 * fase, em português e em alemão — internacionalizar o checkout (país, formato
 * por país, portes) é o sub-projeto 3, fora desta spec.
 */

const MORADA_VAZIA: Morada = {
  etiqueta: '',
  nomeDestinatario: '',
  linha1: '',
  linha2: '',
  codigoPostal: '',
  localidade: '',
  telefone: '',
}

const NOVA = -1

export function FormularioCheckout({
  nome,
  moradas,
}: {
  nome: string
  /** Só as moradas da conta. Nada mais do cliente atravessa para o browser. */
  moradas: Morada[]
}) {
  const router = useRouter()
  const { itens, pronto, esvaziar } = useCarrinho()
  const t = useTranslations('FormularioCheckout')
  const tCheckout = useTranslations('CheckoutPage')

  const [linhas, setLinhas] = useState<LinhaCarrinho[]>([])
  const [aCarregar, setACarregar] = useState(true)
  const [escolhida, setEscolhida] = useState<number>(moradas.length > 0 ? 0 : NOVA)
  const [nova, setNova] = useState<Morada>({ ...MORADA_VAZIA, nomeDestinatario: nome })
  const [guardar, setGuardar] = useState(true)
  const [aEnviar, setAEnviar] = useState(false)
  const [erro, setErro] = useState('')
  const [semStock, setSemStock] = useState<FaltaStock[]>([])

  const chave = JSON.stringify(itens)

  useEffect(() => {
    if (!pronto) return
    let atual = true

    void carregarLinhas(JSON.parse(chave) as typeof itens).then((r) => {
      if (!atual) return
      setLinhas(r.linhas)
      setACarregar(false)
    })

    return () => {
      atual = false
    }
  }, [chave, pronto])

  const totais = totaisDoCarrinho(linhas)
  const moradaEscolhida = escolhida === NOVA ? nova : (moradas[escolhida] ?? nova)

  async function confirmar(evento: React.FormEvent) {
    evento.preventDefault()
    setAEnviar(true)
    setErro('')
    setSemStock([])

    if (escolhida === NOVA && guardar) {
      // Se falhar, o erro é do código postal e a compra também falharia —
      // dizê-lo aqui poupa uma recusa mais adiante com a mesma causa.
      const g = await guardarMorada(nova)
      if (!g.ok) {
        setErro(g.erro)
        setAEnviar(false)
        return
      }
    }

    const r = await comprar(itens, moradaEscolhida)

    if (r.ok) {
      // Só depois do 201. Esvaziar antes deixava alguém sem carrinho e sem
      // encomenda se o servidor recusasse.
      esvaziar()
      router.push(`/conta/encomendas/${r.encomenda.id}?novo=1`)
      return
    }

    setErro(r.erro)
    setSemStock(r.semStock ?? [])
    setAEnviar(false)
  }

  if (!pronto || aCarregar) {
    return <p className="text-ink-muted">{t('aCarregar')}</p>
  }

  if (linhas.length === 0) {
    return (
      <div className="rounded-card bg-white p-8 text-center shadow-sm">
        <p className="text-lg font-semibold text-ink">{tCheckout('naoHaNadaParaComprar')}</p>
        <Link
          href="/"
          className="mt-6 inline-block rounded-xl bg-terracota px-6 py-3 font-semibold text-white transition-colors hover:bg-terracota-dark"
        >
          {tCheckout('verProdutos')}
        </Link>
      </div>
    )
  }

  return (
    <form onSubmit={confirmar} className="grid gap-8 lg:grid-cols-[1fr_20rem]">
      <div className="min-w-0">
        <h2 className="text-lg font-bold text-ink">{t('moradaEnvio')}</h2>

        {moradas.length > 0 ? (
          <fieldset className="mt-4 flex flex-col gap-3">
            <legend className="sr-only">{t('escolherMorada')}</legend>
            {moradas.map((m, i) => (
              <label
                key={`${m.codigoPostal}-${i}`}
                className="flex cursor-pointer items-start gap-3 rounded-card bg-white p-4 shadow-sm"
              >
                <input
                  type="radio"
                  name="morada"
                  className="mt-1"
                  checked={escolhida === i}
                  onChange={() => setEscolhida(i)}
                />
                <span className="text-sm text-ink">
                  {m.etiqueta ? <strong className="block">{m.etiqueta}</strong> : null}
                  {m.nomeDestinatario}
                  <br />
                  {m.linha1}
                  {m.linha2 ? `, ${m.linha2}` : ''}
                  <br />
                  {m.codigoPostal} {m.localidade}
                  {m.telefone ? <br /> : null}
                  {m.telefone}
                </span>
              </label>
            ))}
            <label className="flex cursor-pointer items-center gap-3 rounded-card bg-white p-4 text-sm text-ink shadow-sm">
              <input
                type="radio"
                name="morada"
                checked={escolhida === NOVA}
                onChange={() => setEscolhida(NOVA)}
              />
              {t('usarOutraMorada')}
            </label>
          </fieldset>
        ) : null}

        {escolhida === NOVA ? (
          <div className="mt-4 grid gap-4 rounded-card bg-white p-4 shadow-sm sm:grid-cols-2">
            <Campo
              id="nomeDestinatario"
              rotulo={t('destinatario')}
              valor={nova.nomeDestinatario}
              obrigatorio
              aoMudar={(v) => setNova({ ...nova, nomeDestinatario: v })}
              className="sm:col-span-2"
            />
            <Campo
              id="linha1"
              rotulo={t('morada')}
              valor={nova.linha1}
              obrigatorio
              aoMudar={(v) => setNova({ ...nova, linha1: v })}
              className="sm:col-span-2"
            />
            <Campo
              id="linha2"
              rotulo={t('moradaCont')}
              valor={nova.linha2}
              aoMudar={(v) => setNova({ ...nova, linha2: v })}
              className="sm:col-span-2"
            />
            <Campo
              id="codigoPostal"
              rotulo={t('codigoPostal')}
              valor={nova.codigoPostal}
              obrigatorio
              padrao="\d{4}-\d{3}"
              dica={t('codigoPostalDica')}
              aoMudar={(v) => setNova({ ...nova, codigoPostal: v })}
            />
            <Campo
              id="localidade"
              rotulo={t('localidade')}

            />
            <label className="flex items-center gap-2 text-sm text-ink sm:col-span-2">
              <input
                type="checkbox"
                checked={guardar}
                onChange={(e) => setGuardar(e.target.checked)}
              />
              {t('guardarMorada')}
            </label>
          </div>
        ) : null}

        <h2 className="mt-8 text-lg font-bold text-ink">{t('oQueVaiComprar')}</h2>
        <ul className="mt-4 flex flex-col gap-3">
          {linhas.map((l) => (
            <li
              key={l.variantId}
              className="flex items-center gap-4 rounded-card bg-white p-4 shadow-sm"
            >
              {l.imagem ? (
                <Image
                  src={l.imagem.url}
                  alt={l.imagem.alt}
                  width={l.imagem.width}
                  height={l.imagem.height}
                  className="h-14 w-14 shrink-0 rounded-lg object-cover"
                />
              ) : null}
              <div className="min-w-0 flex-1">
                <p className="font-semibold text-ink">{l.titulo}</p>
                {l.opcoes ? <p className="text-sm text-ink-muted">{l.opcoes}</p> : null}
                <p className="text-sm text-ink-muted">
                  {l.qty} × {formatEuros(l.precoUnitarioCents)}
                </p>
              </div>
              <span className="font-semibold text-ink">
                {formatEuros(l.precoUnitarioCents * l.qty)}
              </span>
            </li>
          ))}
        </ul>
      </div>

      <aside className="h-fit rounded-card bg-white p-6 shadow-sm">

    </form>
  )
}

function Campo({
  id,
  rotulo,
  valor,
  aoMudar,
  obrigatorio = false,
  tipo = 'text',
  padrao,
  dica,
  className = '',
}: {
  id: string
  rotulo: string
  valor: string
  aoMudar: (v: string) => void
  obrigatorio?: boolean
  tipo?: string
  padrao?: string
  dica?: string
  className?: string
}) {
```

```tsx
'use client'

import { useState } from 'react'
import { useTranslations } from 'next-intl'
import { Link, useRouter } from '../../../i18n/navigation'

import { entrar, registar } from '../../../modules/account/acoes'
import { useCarrinho } from '../../../modules/cart/CarrinhoProvider'

/**
 * Entrar e registar — o mesmo formulário, com um campo a mais no registo.
 *
 * O que interessa aqui é a linha do `entrarNaConta`: assim que há sessão, o
 * carrinho de convidado funde-se no da conta, ficando a **maior** quantidade
 * por variante (nunca a soma). Quem tinha 2 no browser e 2 na conta continua a
 * ter 2.
 *
 * `voltar` chega sempre sem prefixo de idioma (ver Task 9/10) — `router.push`
 * é o `useRouter` locale-aware de `i18n/navigation`, que acrescenta o prefixo
 * certo sozinho.
 */
export function FormularioEntrada({ modo, voltar }: { modo: 'entrar' | 'registar'; voltar: string }) {
  const router = useRouter()
  const { entrarNaConta } = useCarrinho()
  const t = useTranslations('FormularioEntrada')

  const [nome, setNome] = useState('')
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [erro, setErro] = useState('')
  const [aEnviar, setAEnviar] = useState(false)

  const ehRegisto = modo === 'registar'

  async function submeter(evento: React.FormEvent) {
    evento.preventDefault()
    setAEnviar(true)
    setErro('')

    const r = ehRegisto ? await registar(nome, email, password) : await entrar(email, password)

    if (!r.ok) {
      setErro(r.erro)
      setAEnviar(false)
      return
    }

    entrarNaConta(r.clienteId)
    router.push(voltar)
    // As páginas da conta são renderizadas no servidor com o cookie novo.
    router.refresh()
  }

  return (
    <form onSubmit={submeter} className="mt-8 flex flex-col gap-4 rounded-card bg-white p-6 shadow-sm">
      {ehRegisto ? (
        <div>
          <label htmlFor="nome" className="block text-sm font-medium text-ink">
            {t('nome')}
          </label>
          <input
            id="nome"
            name="nome"
            required
            autoComplete="name"
            value={nome}
            onChange={(e) => setNome(e.target.value)}
            className="mt-1 w-full rounded-lg border border-line bg-cream px-3 py-2 text-ink"
          />
        </div>
      ) : null}

      <div>
        <label htmlFor="email" className="block text-sm font-medium text-ink">
          {t('email')}
        </label>
        <input
          id="email"
          name="email"
          type="email"
          required
          autoComplete="email"
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          className="mt-1 w-full rounded-lg border border-line bg-cream px-3 py-2 text-ink"
        />
      </div>

      <div>
        <label htmlFor="password" className="block text-sm font-medium text-ink">
          {t('palavraPasse')}
        </label>
        <input
          id="password"
          name="password"
          type="password"
          required
          minLength={8}
          autoComplete={ehRegisto ? 'new-password' : 'current-password'}
          value={password}
          onChange={(e) => setPassword(e.target.value)}
          className="mt-1 w-full rounded-lg border border-line bg-cream px-3 py-2 text-ink"
        />
      </div>

      {erro ? (
        <p
          role="alert"
          className="rounded-lg border border-terracota bg-terracota/10 px-3 py-2 text-sm text-ink"
        >
          {erro}
        </p>
      ) : null}

        disabled={aEnviar}

          className="underline hover:text-ink"
        >
          {ehRegisto ? t('entrar') : t('criarConta')}
        </Link>
      </p>
    </form>
  )
}
```

```ts
export const estadoLegivel = (estado: string, t: (chave: string) => string): string => {
  const chave = CHAVES_ESTADO[estado]
  return chave ? t(chave) : estado
}

const LOCALE_DATA: Record<string, string> = { pt: 'pt-PT', de: 'de-DE' }

export const dataLegivel = (iso: string, locale: string): string =>
  new Date(iso).toLocaleDateString(LOCALE_DATA[locale] ?? locale, {
    day: '2-digit',
    month: 'long',
    year: 'numeric',
  })
```

```tsx
'use client'

import { useEffect, useState } from 'react'
import { useTranslations } from 'next-intl'
import { Link } from '../../i18n/navigation'

import { alternarFavorito, ehFavorito } from '../../modules/account/acoes'
import { Icon } from '../icons/sprite'

/**
 * O coração da ficha de produto.
 *
 * Pergunta o estado depois de montar, em vez de o receber do servidor: a ficha
 * de produto é gerada estaticamente (`generateStaticParams`), e ler a sessão no
 * servidor para pintar um coração passava a página inteira a dinâmica — o
 * catálogo perdia o pré-render para desenhar um ícone.
 *
 * `null` quer dizer "sem sessão": aí não há coração para alternar, há um convite
 * a entrar. Um coração que não guarda nada é pior do que coração nenhum.
 */
export function BotaoFavorito({ productId }: { productId: number }) {
  const [favorito, setFavorito] = useState<boolean | null>(null)
  const [carregado, setCarregado] = useState(false)
  const [erro, setErro] = useState('')
  const t = useTranslations('BotaoFavorito')

  useEffect(() => {
    void ehFavorito(productId).then((estado) => {
      setFavorito(estado)
      setCarregado(true)
    })
  }, [productId])

  if (!carregado) return null

  if (favorito === null) {
    return (
      <Link
        href="/conta/entrar"
        className="inline-flex items-center gap-2 text-sm font-medium text-ink-muted underline transition-colors hover:text-ink"
      >
        <Icon name="heart" className="h-4 w-4" />
        {t('entrarParaGuardar')}
      </Link>
    )
  }

  return (
    <div>
      <button
        type="button"
        aria-pressed={favorito}
        onClick={() => {
          void alternarFavorito(productId).then((r) => {
            if (r.ok) {
              setFavorito(r.favorito)
              setErro('')
            } else {
              setErro(r.erro)
            }
          })
        }}
        className={`inline-flex items-center gap-2 rounded-lg border px-3 py-2 text-sm font-medium transition-colors ${
          favorito
            ? 'border-terracota bg-terracota/10 text-terracota-dark'
            : 'border-line text-ink-muted hover:text-ink'
        }`}
      >
        <Icon name="heart" className="h-4 w-4" />
        {favorito ? t('nosFavoritos') : t('guardarNosFavoritos')}
      </button>
      {erro ? <p className="mt-2 text-sm text-terracota-dark">{erro}</p> : null}
    </div>
  )
}
```

```tsx
  titulo: string
  texto: string
  ctaPrincipal: { texto: string; href: string }

 * `components/motion` (`useMotion`) porque não é "anima uma vez ao aparecer":
```
